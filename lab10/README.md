# CONTROL Lab10 — tutoriales Wild Rift (sin APK)

## Alcance real
Este laboratorio es un **catalogo de fuentes y plan de estudio**, NO un modelo que ya haya visto videos ni una mejora implementada en el detector. No se descarga contenido de terceros ni se asegura que CONTROL haya aprendido mirando YouTube.

### Proceso de trabajo
1. Verificar y fechar tutoriales; preferir documentacion oficial de Riot para reglas y parches.
2. Obtener transcripciones o fotogramas solo si se dispone de acceso y permiso adecuados, registrando URL, fecha, tramo y version de Wild Rift.
3. Redactar hechos comprobables (HUD, campeon, habilidad, objetivo, condicion, contraejemplo) con procedencia. Mantener guias antiguas separadas de mecanicas actuales.
4. Comparar con las tres capturas etiquetadas por Wolf: personaje verde = jugador, azul = aliado, rojo = enemigo en esas capturas; NO asumir que todos los HUD tienen colores identicos.
5. Evaluar ejemplos reales de gameplay en conjunto retenido, sin mezclarlo con los ejemplos de construccion. Registrar errores, incertidumbre y rendimiento.
6. Convertir reglas aprobadas en pruebas unitarias del motor tactico; no entrenar sobre opiniones como si fueran labels visuales.
7. Solo despues de certificar captura Android, abordar integracion progresiva. No generar una APK desde este laboratorio.

## Material inicial
Ver `tutorial_sources.json`. Los dos enlaces de YouTube tienen titulo/descripcion identificados, pero **su video no fue reproducido ni transcrito por este laboratorio**. La ficha oficial y notas de parche son referencias para revision. Ningun video ni captura es almacenado aqui.

## Seguridad y costo
Mantener trabajo en rama aislada, sin API paga, sin videos redistribuidos, sin imagenes de terceros incluidas en el repositorio. Versiones y valores numericos deben comprobarse con las notas de parche vigentes.
